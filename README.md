# IISc Theme

IISc (Indian Institute of Science) branded Desk theme for Frappe v16 + Frappe HR.

- Brand colours: Navy `#1B374C`, Teal `#108896`, Blue `#006699`, Orange `#EE5030`
- Assets: `iisc_theme/public/css/iisc_theme.bundle.css`, `iisc_theme/public/js/iisc_theme.bundle.js`
- Replace the placeholder logo/favicon in `iisc_theme/public/images/` with official IISc files (same file names).
